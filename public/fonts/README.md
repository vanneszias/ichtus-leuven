# Website fonts

The public site uses the project-provided Internet Friends display font and
Instrument Sans from Fontsource. Instrument Sans is distributed under the SIL
Open Font License 1.1; its package license is retained in `node_modules`.

`internet-friends.ttf` was supplied by the project owner. Its embedded metadata
identifies Font.My as the creation tool. Production usage rights are not yet
documented. A release must remain blocked with
`FONT_PRODUCTION_LICENSE_CONFIRMED=false` until the organization records the
license or replaces the font with a documented production-safe alternative.

Do not add font binaries to this directory without recording their source and
production license here.
